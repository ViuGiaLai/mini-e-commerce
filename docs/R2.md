# Cloudflare R2 media storage

ViuFilm3D dùng R2 để lưu video, poster, phụ đề và audio. Khóa R2 chỉ được đọc bởi Next.js server. Trình duyệt tải file trực tiếp lên R2 bằng presigned `PUT` URL có thời hạn 15 phút.

## Biến môi trường

```ini
R2_ACCESS_KEY_ID=your_access_key_id
R2_SECRET_ACCESS_KEY=your_secret_access_key
R2_ENDPOINT=https://your_account_id.r2.cloudflarestorage.com
R2_BUCKET=viufilm-media
```

Không thêm tiền tố `NEXT_PUBLIC_` vào bất kỳ biến nào ở trên.

Kiểm tra kết nối mà không in khóa bí mật:

```bash
npm run r2:check
```

Token R2 chỉ cần quyền **Object Read & Write** trên bucket `viufilm-media`. Không dùng token quản trị toàn tài khoản nếu không cần thiết.

## Cấu hình CORS

Trong **Cloudflare Dashboard → R2 → viufilm-media → Settings → CORS policy**, thêm:

```json
[
  {
    "AllowedOrigins": [
      "http://localhost:3000",
      "https://mini-e-commerce-3l2u.onrender.com"
    ],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["Content-Type"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

Hoặc áp dụng bằng S3 API; script giữ nguyên các rule khác và chỉ cập nhật rule của ViuFilm3D:

```bash
npm run r2:cors
```

Nếu đổi domain production, cập nhật `AllowedOrigins`. Không dùng `*` cho trang quản trị production.

## Luồng upload

1. Admin chọn file trong form phim.
2. Frontend gửi tên, loại, MIME type và dung lượng tới `/api/v1/media/presign`.
3. Backend kiểm tra phiên admin, định dạng, dung lượng và sinh object key.
4. Backend ký presigned `PUT` URL bằng R2 credentials.
5. Trình duyệt tải file thẳng lên R2 với đúng `Content-Type`.
6. Frontend gọi `/api/v1/media/complete`.
7. Backend dùng `HeadObject` kiểm tra tệp thật rồi trả object key.
8. Phim chỉ lưu object key; khi phát, `/api/v1/media/url` tạo presigned `GET` URL ngắn hạn.

## Cấu trúc object key

```text
movies/{movieId}/{category}/{uuid}-{safeFilename}
```

Ví dụ:

```text
movies/12/video/4f3...-tap-01.mp4
movies/12/poster/a91...-poster.webp
movies/12/subtitle/c82...-vi.vtt
movies/12/audio/aa7...-thuyet-minh.mp3
```

Tên file được chuẩn hóa và UUID ngăn ghi đè tệp cũ.

## API media

- `POST /api/v1/media/presign`: tạo quyền upload, yêu cầu admin.
- `POST /api/v1/media/complete`: kiểm tra tệp sau upload, yêu cầu admin.
- `GET /api/v1/media/url?key=...`: tạo URL đọc có thời hạn.
- `GET /api/v1/media?prefix=...`: liệt kê object, yêu cầu admin.
- `DELETE /api/v1/media`: xóa object, yêu cầu admin.

## Giới hạn của ứng dụng

- Video: 2 GB.
- Poster: 15 MB.
- Phụ đề WebVTT (`.vtt`): 5 MB.
- Audio: 250 MB.

Upload hiện dùng một presigned `PUT`. Nếu cần video lớn hơn 2 GB hoặc resume upload, bổ sung multipart upload thành một module riêng.

## Production

Thêm bốn biến R2 vào **Render → Environment**. Đây là runtime secrets, không phải Docker build arguments và không được thêm vào GitHub Actions logs.

R2 bucket có thể giữ private vì ứng dụng dùng presigned `GET` URL. Nếu sau này dùng custom domain public cho poster, có thể thêm `R2_PUBLIC_URL` và cache CDN, nhưng không nên bật `r2.dev` cho production.
